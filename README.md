# Exploring JavaScript compile targets of Dafny, Agda, and Idris2

A small comparison project. For each of three provable problems we have
side-by-side implementations in all three tools, scripts that compile +
run each output, and probes that evaluate the SES (Hardened JavaScript)
compatibility of the generated JS and the ease of calling the verified
functions from external JavaScript.

## Layout

```
problems/
  factorial/        — recursive Nat → Nat with positivity proof
  reverse/          — list reverse with reverse-reverse-identity theorem
  insertion-sort/   — verified sortedness (Agda/Idris2) + multiset preservation (Dafny)
    <each>/dafny/   — Dafny source
    <each>/agda/    — Agda source
    <each>/idris2/  — Idris2 source

generator/
  problems.js       — declares how each impl builds, runs, and where its JS output lives
  build.js          — compile + run every implementation, dump results.json
  ses-check.js      — static + lockdown() + Compartment SES probes
  ffi-probe.js      — try calling the verified `sort` from external JS in each lang
  report.js         — render docs/<problem>.md from results.json

outputs/            — autogenerated JSON manifests per problem + ffi-probe.json
docs/               — autogenerated per-problem comparison markdown
EVALUATION.md       — hand-written analysis across all three dimensions
flake.nix           — pins dafny / agda / idris2 / nodejs from nixpkgs
```

## Setup

NixOS / Nix-with-flakes (default):

```
nix develop          # drops you in a shell with dafny, agda, idris2, node
npm install          # bignumber.js (Dafny runtime dep) + ses (the SES package)
```

Otherwise, install Dafny 4.11+, Agda 2.8+, Idris2 0.8+, and Node 22+ by your own means.

## Run the full pipeline

```
node generator/build.js       # ~30 s after the toolchains are cached
node generator/ses-check.js   # ~10 s
node generator/ffi-probe.js   # ~3 s
node generator/report.js      # instant
```

This regenerates everything under `outputs/` and `docs/`.
